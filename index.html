ChirpyLi Helm Charts

Neon Serverless Postgres — 私有化部署 Helm Chart 仓库

helm repo add chirpyli https://chirpyli.github.io/helm-charts/

快速开始

# 添加 Helm 仓库 helm repo add chirpyli https://chirpyli.github.io/helm-charts/ # 更新仓库索引 helm repo update # 查看可用 charts helm search repo chirpyli # 安装 neon-stack（完整私有化部署） helm install my-neon chirpyli/neon-stack --namespace neon --create-namespace

可用 Charts

neon-stack 🌩️ 最新版本 Neon 完整私有化部署 Umbrella Chart，一键部署全部组件 Neon 源码
neon-pageserver 核心组件 Neon Pageserver：处理 WAL 日志，提供 page 服务
neon-safekeeper 核心组件 Neon Safekeeper：WAL 可靠存储，确保数据持久性
neon-compute 核心组件 Neon Compute：PostgreSQL 计算节点
neon-storage-controller 基础设施 Neon Storage Controller：管理存储分片与调度
neon-storage-broker 基础设施 Neon Storage Broker：对象存储代理服务
neon-proxy 网络层 Neon Proxy：客户端连接代理与路由
neon-pg-sni-router 网络层 SNI Router：基于 SNI 的多租户路由

特性

⚡ Serverless Postgres — 计算存储分离
📦 一键私有化部署 (neon-stack umbrella)
🔄 Branch 分支 — 即时数据库克隆
💾 WAL 可靠存储 — Safekeeper 多副本
📊 弹性伸缩 — 计算节点按需扩展
🌐 多租户路由 — SNI + Proxy 代理层
🪣 对象存储后端 — S3 兼容存储
📈 Prometheus 监控集成

查找 Chart 版本

# 搜索特定 chart 的所有可用版本 helm search repo chirpyli --versions # 查看 chart 详细信息 helm show chart chirpyli/neon-stack # 查看 chart 可配置参数 helm show values chirpyli/neon-stack
