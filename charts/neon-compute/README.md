## 简介

`neon-compute` 是一个**静态/演示 compute 回退方案**，以 Deployment 部署运行 PostgreSQL + `compute_ctl`。

- 通过 `compute_ctl -c /etc/neon/spec.json` 加载 ComputeSpec 文件启动
- ComputeSpec 由 control plane 在创建 endpoint 时生成
- 适用于**无 K8s 写权限环境**或快速演示场景

> **推荐路径**：生产环境建议由 control plane 通过 in-cluster K8s API 动态拉起 compute Deployment（设置 `neon-control-plane.settings.enableK8sCompute=true`）。本 chart 作为静态回退/演示使用。

## 架构要点

| 资源 | 说明 |
|------|------|
| Deployment | 无状态计算节点 |
| ClusterIP Service | 暴露 postgres 5432 + compute_ctl 3080 |
| ConfigMap | 存放 ComputeSpec JSON（`/etc/neon/spec.json`） |
| ServiceAccount | 运行时身份标识 |

## ComputeSpec 关键字段

ComputeSpec 中控制 compute 行为的关键字段：

- `pageserver_connection_info`：pageserver 连接信息（`libpq_url` / `grpc_url`）
- `safekeeper_connstrings`：safekeeper 地址列表
- `storage_auth_token`：由 control plane 签发的 JWT（scope=PageServerApi,SafekeeperData）
- `cluster.roles[].encrypted_password`：SCRAM-SHA-256 验证器（角色认证用）

## 安装

```console
$ helm repo add neondatabase https://neondatabase.github.io/helm-charts
$ helm install neon-compute neondatabase/neon-compute \
    --set-file settings.spec=/path/to/compute-spec.json
```

通过 umbrella chart 一键部署（推荐）：

```console
$ helm install neon ./charts/neon
```

## 前置依赖

- **control plane**：生成 ComputeSpec（需先完成 bootstrap 并创建 endpoint）
- **pageserver**：运行中的 pageserver 节点
- **safekeeper**：运行中的 safekeeper 集群（>= 3 副本）
